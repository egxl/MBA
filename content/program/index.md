# P3MD MBA Program Architecture & Governance

The **P3MD MBA** (_Program Pendidikan Profesional Magister Terapan_) is an executive leadership ecosystem engineered by **SBM ITB** (_Direktorat Pendidikan Profesional Berkelanjutan_) in strategic collaboration with the **Kementerian Pertahanan Republik Indonesia (Kemhan RI)**, **DIKTISAINTEK BERDAMPAK**, and **Danantara Indonesia** (_Daya Anagata Nusantara_).

Hosted at the residential **Kampus DCU Nawasena**, the program is built on an integrated development architecture designed to transform high-potential leaders into strategic business executives under the ethos:

$$\mathbf{LEARN \quad \boldsymbol{\cdot} \quad LEAD \quad \boldsymbol{\cdot} \quad EXECUTE}$$

## 🧭 The 5 Components for Transformation

```
  ┌─────────────────────────────────────────────────────────────┐
  │                   1. Desain Kurikulum                       │
  │     Foundation Learning  •  6 Core Courses  •  Leadership   │
  └──────────────────────────────┬──────────────────────────────┘
                                 │
  ┌──────────────────────────────▼──────────────────────────────┐
  │                  2. Metode Pembelajaran                     │
  │    Case-Based (Harvard)  •  Simulasi & Gamifikasi  •  LMS   │
  └──────────────────────────────┬──────────────────────────────┘
                                 │
  ┌──────────────────────────────▼──────────────────────────────┐
  │               3. Action Learning Project (ALP)              │
  │     Real BUMN Business Challenges  •  SMART Gate Impact     │
  └──────────────────────────────┬──────────────────────────────┘
                                 │
  ┌──────────────────────────────▼──────────────────────────────┐
  │                    4. Sistem Mentoring                      │
  │    SBM ITB  •  BUMN Mentors  •  Coaches  •  Pengasuh  •  PO │
  └──────────────────────────────┬──────────────────────────────┘
                                 │
  ┌──────────────────────────────▼──────────────────────────────┐
  │                5. Operasional & Fasilitas                   │
  │    Nawasena Living-Learning Environment (24h Clinic, Accom) │
  └──────────────────────────────┬──────────────────────────────┘
                                 │
  ┌──────────────────────────────▼──────────────────────────────┐
  │                        TARGET OUTCOME                       │
  │  Responsible Decision-Makers  •  Cross-Functional Execution  │
  └─────────────────────────────────────────────────────────────┘
```

1. **Desain Kurikulum**: 3 building blocks — Foundation Learning (agility, strategic thinking, accounting), 6 Core Courses across 6 BUMN sectors, and Managerial/Leadership/Entrepreneurship capabilities.
2. **Metode Pembelajaran**: Blended case-based exposure using Harvard Business School case studies, simulation games, and continuous reflection.
3. **Action Learning Project (ALP)**: Rigorous engagement with actual business challenges in state-owned enterprises (BUMN) with measurable business impact.
4. **Sistem Mentoring**: 5-tier layered support ecosystem (Academic depth, BUMN industrial reality, leadership coaching, character/discipline guidance, and project sponsorship).
5. **Operasional & Fasilitas**: Dedicated infrastructure at Kampus DCU Nawasena supporting round-the-clock living-learning immersion.
