# Action Learning Project (ALP) Blueprint

> _"Learning through real business challenges with measurable impact."_

The **Action Learning Project (ALP)** is the central experiential pillar of the P3MD MBA. Deployed across **10 partner state-owned enterprises (BUMN)**, participants work in cross-functional small groups ($\pm$10 executives) to dissect, model, and resolve actual high-stakes strategic dilemmas under real commercial constraints.

---

## 1. Core Philosophy & The Carpenter Analogy

```
┌───────────────────────────┐     ┌───────────────────────────┐     ┌───────────────────────────┐
│   Equip & Transform       │     │     Real Business ROI     │     │       True Test of        │
│ Participant Capabilities  │ ──► │     that Creates Value    │ ──► │    Agility & Resilience   │
└───────────────────────────┘     └───────────────────────────┘     └───────────────────────────┘
```

> **The Carpenter Analogy:**  
> _"Tukang bangunan yang tahu menggunakan alat, belum tentu bisa membuat rumah. Hanya pengalaman dalam membuat rumah maka ia dapat menggunakan keahliannya."_  
> _(A carpenter who knows how to use individual tools cannot necessarily build a house. Only the lived experience of building a house turns technical knowledge into true mastery.)_

### Key Evaluative Questions:

1. **Managing Ambiguity**: Can this executive navigate ill-structured business environments, missing data, and volatile stakeholder requirements rather than merely executing structured assignments?
2. **Real-Time Pressure**: Can the team collaborate cohesively under strict deadlines without compromising analytical rigor?
3. **Executive Readiness**: Is the participant prepared to step into a wider, less-defined enterprise mandate?

---

## 2. Defining a "Stretch" Assignment

To qualify as an executive ALP, each project deliverable must fulfill five core criteria:

- [x] **Grounded Fact Base**: A granular, unambiguous diagnosis of the root problem, validated through primary field data, financial disclosures, and stakeholder interviews.
- [x] **Explicit Strategic Trade-offs**: A distinct set of mutually exclusive strategic options, with clear articulation of trade-offs, opportunity costs, and downside risks.
- [x] **Financially-Aware Recommendations**: High-fidelity valuation and cost-benefit projections (NPV, IRR, capital expenditure requirements, payback periods).
- [x] **Execution Architecture**: A tactical implementation roadmap covering organizational design, change management, governance, and technology requirements.
- [x] **Actionable Deliverables**: Concrete recommendations that a BUMN board or enterprise sponsor can execute immediately.

## 3. The 6 SMART-Gated Stages (M2 – M16)

The project unfolds across 6 progressive phases gated by **SMART criteria** (_Specific, Measurable, Achievable, Relevant, Time-Bound_):

```
┌──────────────────┐    ┌──────────────────┐    ┌──────────────────┐
│ 1. Scoping       │───►│ 2. Data          │───►│ 3. Analysis      │
│    (Weeks 2–3)   │    │    (Weeks 4–6)   │    │    (Weeks 7–9)   │
└──────────────────┘    └──────────────────┘    └──────────────────┘
                                                          │
┌──────────────────┐    ┌──────────────────┐    ┌─────────▼────────┐
│ 6. Final Defense │◄───│ 5. Coach Review  │◄───│ 4. Solution      │
│    (Weeks 15–16) │    │    (Weeks 13–14) │    │    (Weeks 10–12) │
└──────────────────┘    └──────────────────┘    └──────────────────┘
```

### Stage Breakdown

| Stage                     |  Timeline   | Primary Objectives                                                                                              | Key Deliverables & Gates                                             |
| :------------------------ | :---------: | :-------------------------------------------------------------------------------------------------------------- | :------------------------------------------------------------------- |
| **1. Problem Scoping**    |  Weeks 2–3  | Formal alignment with BUMN Project Owner to identify high-leverage business issues.                             | Approved Project Charter & Problem Statement.                        |
| **2. Data Gathering**     |  Weeks 4–6  | Primary stakeholder interviews, internal operational data audit, and customer/market surveys.                   | Comprehensive Fact Pack & Diagnostic Findings.                       |
| **3. Analysis**           |  Weeks 7–9  | Multi-disciplinary synthesis combining strategy, corporate finance, HR/organizational behavior, and operations. | Root-Cause Analysis & Value-Creation Hypotheses.                     |
| **4. Solution Design**    | Weeks 10–12 | Formulating concrete intervention options, financial modeling, and implementation feasibility checks.           | Option Comparison Matrix & Business Case Model.                      |
| **5. Coaching Review**    | Weeks 13–14 | Rigorous stress-testing of recommendations with SBM ITB coaches and enterprise Project Owners.                  | Pre-Defense Advisory Deck & Executive Summary.                       |
| **6. Final Presentation** | Weeks 15–16 | Formal defense before a panel of BUMN executive leadership, ministry partners, and faculty evaluators.          | Final Board Presentation, Financial Model & Implementation Playbook. |
